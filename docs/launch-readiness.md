## Технические замечания
- 23 ноября 2026: первая успешная проверка ссылок прошла по 16 ближайшим конкурсам: 15 ответили HTTP 200, 0 ответов 404/410; у сайта `www.teatr-subbota.ru` произошёл сетевой сбой, который оставлен предупреждением для повторной проверки, а не объявлен битой ссылкой.\n- Защита от скомпрометированных паролей отключена из-за ограничений текущего бесплатного тарифа; не утверждать, что она включена.
- Performance Advisor ранее сообщал о внешних ключах без покрывающих индексов. Это не блокер для небольшого пилота, но стоит оценить запросы и добавить индексы при подтверждённой пользе.
- GitHub Actions workflow проверяет доступность сайта один раз в день. Это базовый сигнал, не полноценный мониторинг или гарантия SLA.
- Текущая резервная копия охватывает базу, но не файлы Supabase Storage и не является доказательством полного восстановления проекта.
