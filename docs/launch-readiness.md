## Требует ручной проверки перед открытым запуском

### Supabase Auth
- [ ] Включить защиту от скомпрометированных паролей в Auth settings, если настройка доступна на текущем тарифе.
- [ ] Проверить минимальную длину пароля на стороне Supabase (не только HTML).
- [ ] Проверить разрешённые Redirect URLs для текущего GitHub Pages URL и будущего домена.
- [ ] Проверить полный путь сброса пароля на настоящем тестовом аккаунте: письмо → ссылка → новый пароль → повторный вход.
- [ ] Проверить ограничение частоты входа/регистрации и CAPTCHA/anti-bot, если доступно.

### Доступ к данным
- [ ] Протестировать два отдельных аккаунта: дневник, проекты, заметки, заявки, профиль, подписки, достижения и лента не должны показывать чужие данные вне предусмотренных правил.
- [ ] Проверить все 8 оставшихся SECURITY DEFINER RPC-функций на реальных ролях. Они оставлены доступными, поскольку часть нужна UI/RLS и имеет проверки авторизации; предупреждение Advisor само по себе не доказывает уязвимость.
- [ ] Политика `profiles_select_authenticated` позволяет всем вошедшим читать поля профиля. Это похоже на намеренный каталог авторов, но владелец должен подтвердить, что bio, avatar, social URL и donation URL считаются видимыми другим участникам.
- [ ] Бакет `writer-avatars` в Supabase Storage помечен как public (лимит 8 МБ, MIME allowlist JPG/PNG/WebP/AVIF). Значит, изображения доступны по URL; подтвердить, что это намеренно, и объяснить это в политике приватности.
- [ ] Таблицы `club_invitations`, `monthly_association_rating_snapshots` и `monthly_individual_rating_snapshots` имеют включённый RLS без политик. Это закрывает прямой доступ через RLS; подтвердить, что прямой доступ не нужен и функции SECURITY DEFINER корректно обслуживают предусмотренные сценарии.
- [ ] Проверить, что в клиентском коде нет service_role/secret key, а все реальные секреты хранятся только в GitHub Secrets.
- [ ] Проверить экспорт, восстановление и удаление аккаунта/данных.

### Домен, документы и контакты
- [ ] Владелец выбирает и регистрирует домен; до этого нельзя установить canonical URL на окончательный домен.
- [ ] После подключения домена обновить canonical/og:url, Auth Redirect URLs и ссылки подтверждения email.
- [ ] Подготовить и юридически проверить политику конфиденциальности и пользовательское соглашение с реальными сведениями о владельце, месте хранения/обработки данных и контактами.
- [ ] Указать рабочий адрес поддержки/контакт для запросов об удалении данных и жалоб.
- [ ] Определить возрастные правила и дополнительные меры безопасности для несовершеннолетних.

### Публичная готовность
- [ ] Проверить сайт на реальных мобильных устройствах и пройти все ключевые сценарии клавиатурой.
- [ ] Провести закрытый пилот с 15–25 авторами; зафиксировать проблемы регистрации, первого проекта, синхронизации и возврата.
- [ ] Подготовить сообщение о том, что каталог конкурсов собирается автоматически и условия нужно сверять с официальным положением.

## Текущие замечания Supabase Security Advisor

- Информационные предупреждения: три таблицы с включённым RLS без политик. Не открывать их политиками просто ради исчезновения предупреждения.
- Восемь оставшихся предупреждений про SECURITY DEFINER относятся к RPC-функциям, которые вызываются авторизованным интерфейсом или нужны для проверки членства/чтения разрешённых данных. Их надо проверять по каждой функции и сценарию, а не массово отзывать EXECUTE.
- Защита от скомпрометированных паролей отключена — включить в настройках Auth.
- Performance Advisor сообщает о внешних ключах без покрывающих индексов. Это не блокер для небольшого пилота; добавить индексы после проверки реальных запросов и нагрузки.

## Что требует участия владельца

1. Выбор домена и оплата регистрации.
2. Рабочий контакт для поддержки и юридических запросов.
3. Подтверждение, какие поля профиля должны быть видны всем зарегистрированным авторам.
4. Решение о минимальном возрасте пользователей и правилах для несовершеннолетних.
5. Тест сброса пароля с доступом к тестовому почтовому ящику.
6. Юридическая проверка политики конфиденциальности и соглашения перед открытой регистрацией.
